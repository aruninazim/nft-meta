NFT metadata stub — job id as token tag.

## Features

- Algorithm tag sha256
- Stub job + nonce scan
- No GPU/CUDA runtime required

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd nft-meta
cargo build --release
./target/release/nft-meta --help
```

## Tests

```bash
cargo test
```
